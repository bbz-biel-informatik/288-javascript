Eine gemeinsame Basis

Eine VitePress-App liefert Landingpage, Kursinhalte und Projektdokumentation unter einer klaren URL-Struktur aus.

Markdown-first

Inhalte bleiben in Markdown, Bilder liegen unter docs/assets und Codebeispiele können direkt aus Quelldateien importiert werden.

Lokal deploybar

Build und Deployment passieren lokal mit npm-Skripten. GitHub Actions sind nicht Teil dieses Setups.

Bereiche ​

  • Kurs für das Unterrichtsskript und Kapitelstruktur
  • Game für die kleine Projektdokumentation
  • Library für die Dokumentation der kleinen Bibliothek

Platz für weitere Bereiche ​

Workshops

Reservierter Platz für zusätzliche Unterrichtsformate oder Spezialthemen.

Referenzen

Kann später für Cheatsheets, Glossar oder externe Links erweitert werden.

Projekte

Eignet sich für weitere Dokumentationsbereiche wie Tools, Demos oder Abschlussarbeiten.
