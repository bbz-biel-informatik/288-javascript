# Loops / Listen

Listen speichern mehrere Werte. Loops helfen, diese Werte nacheinander zu verarbeiten.

## Array

```js
const colors = ["red", "green", "blue"];
```

## Loop

```js
for (const color of colors) {
  console.log(color);
}
```

## Typischer Einsatz

Bei einer Spiel- oder UI-Logik willst du oft mehrere Elemente gleich behandeln, zum Beispiel Hindernisse, Karten oder Einträge in einer Liste.
