Diagramm-Notizen
================

Dieser Ordner ist fuer Diagrammquellen gedacht, zum Beispiel .excalidraw-Dateien.

Empfehlung
----------

- Quellformat hier ablegen, zum Beispiel spielablauf.excalidraw
- Exportierte Bilder als .svg oder .png nach docs/assets/images/ legen
- In Markdown immer auf die exportierte Bilddatei verlinken

So bleiben die editierbaren Quellen und die eingebundenen Bilder sauber getrennt.
