# Funktionen

Funktionen bündeln wiederverwendbare Schritte unter einem Namen.

## Einfaches Beispiel

```js
function greet(name) {
  return `Hallo ${name}`;
}

console.log(greet("Nora"));
```

## Warum Funktionen wichtig sind

- Wiederholungen werden reduziert.
- Logik bleibt besser lesbar.
- Ereignisse lassen sich klar an kleine Aufgaben koppeln.
