# If / Else

Mit `if / else` reagiert dein Programm auf Bedingungen.

## Beispiel

```js
const score = 12;

if (score >= 10) {
  console.log("Level geschafft");
} else {
  console.log("Noch einmal versuchen");
}
```

## Warum das wichtig ist

- Spiellogik reagiert auf Zustände.
- Formulare können Eingaben prüfen.
- Oberflächen können abhängig von Daten anders aussehen.
