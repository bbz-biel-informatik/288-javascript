# Aufgabe - Click Game Score

In der vorherigen Aufgabe hast du ein Click Game erstellt. Jetzt erweitern wir das Spiel, damit es einen Score gibt, der bei jedem Klick erhöht wird.

### 1: Score hinzufügen

**Ziel:**  
Erstelle einen Score, der bei jedem Klick **um 1 erhöht wird**.

**Tipps:**

- Erstelle eine Variable: `let score = 0;`
- Verwende `textContent`, um den Score im HTML anzuzeigen. Hilfe dazu findest du in [2.2 - DOM Elemente verändern](/modul/2-html-elemente-mit-javascript-veraendern/2-2-dom-elemente-veraendern).

## 5: Bonus

- Ändere die Farbe bei jedem Klick zufällig 🎨
- Mache das Element kleiner, je höher der Score ist
- Füge einen Timer hinzu ⏱️
