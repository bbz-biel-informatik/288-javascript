# if - else

Dummy Inhalt fuer das Kapitel if - else.

## Worum geht es?

Mit `if`, `else if` und `else` entscheidest du, welcher Code ausgefuehrt wird.

```js
let score = 10;

if (score > 5) {
  console.log("Gewonnen");
} else {
  console.log("Weiter ueben");
}
```

## Aufgabe

Erstelle eine Variable `score` und pruefe mit `if`, ob der Wert groesser als `10` ist.
