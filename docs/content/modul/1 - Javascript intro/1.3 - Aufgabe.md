# Projekt Setup Aufgabe

## Editor setup
- Download und installiere [Visual Studio Code](https://code.visualstudio.com/).
- Erstelle einen neuen Ordner (z.B. `javascript-project`) und öffne diesen in VS Code.
- Erstelle ein file `index.html` mit einem einfachen HTML-Grundgerüst.
- Installiere und teste die nötigen Extensions (Siehe vorangehendes Kapitel)
- Aktiviere und teste Auto Save in den VS Code Einstellungen, damit Änderungen automatisch gespeichert werden.
