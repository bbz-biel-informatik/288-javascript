# Javascript 

Willkommen zum Javascript-Modul. Dieser Bereich bündelt die Kapitel für den Unterricht und bleibt bewusst einfach aufgebaut, damit du neue Seiten schnell ergänzen kannst.

## Einfaches Beispiel

```js
function greet(name) {
  return `Hallo ${name}`;
}

console.log(greet("Nora"));
```
