# Listen und Loops

Dummy Inhalt fuer das Kapitel Listen und Loops.

## Worum geht es?

Listen speichern mehrere Werte. Loops helfen dir, jeden Eintrag einer Liste nacheinander zu bearbeiten.

```js
let names = ["Nora", "Max", "Lina"];

names.forEach(function (name) {
  console.log(name);
});
```

## Aufgabe

Erstelle eine Liste mit drei Namen und gib jeden Namen einzeln in der Konsole aus.
