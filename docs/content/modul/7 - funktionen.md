# Funktionen

Dummy Inhalt fuer das Kapitel Funktionen.

## Worum geht es?

Funktionen fassen Code zusammen, damit du ihn mehrfach verwenden kannst.

```js
function greet(name) {
  return "Hallo " + name;
}

console.log(greet("Nora"));
```

## Aufgabe

Schreibe eine Funktion `double(number)`, die eine Zahl verdoppelt und das Resultat zurueckgibt.
