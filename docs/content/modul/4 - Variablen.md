# Variablen

Dummy Inhalt fuer das Kapitel Variablen.

## Worum geht es?

Variablen speichern Werte, die spaeter im Programm wieder verwendet oder veraendert werden koennen.

```js
let score = 0;
score = score + 1;
console.log(score);
```

## Aufgabe

Erstelle eine Variable `score`, erhoehe sie um `1` und gib den Wert mit `console.log()` aus.
