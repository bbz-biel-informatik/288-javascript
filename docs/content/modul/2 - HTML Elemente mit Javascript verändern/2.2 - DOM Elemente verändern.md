# DOM Elemente verändern

Wenn du ein Element ausgewählt hast, kannst du Text, HTML oder CSS mit Javascript anpassen.

## Styles ändern

```js
myImage.style.color = "red";
```

Damit änderst du eine CSS-Eigenschaft direkt mit Javascript.

## Text ändern

```js
myImage.textContent = "Hello";
```

Mit `textContent` setzt du normalen Text in ein Element.

> Im Cheatsheet verwenden wir `textContent` für Textinhalte.

## HTML einfügen

```js
myImage.innerHTML = "<b>Hello</b>";
```

Mit `innerHTML` fügst du HTML-Code in ein Element ein.

## Klassen hinzufügen oder entfernen

```js
myImage.classList.add("active");
myImage.classList.remove("active");
```

Damit kannst du CSS-Klassen dynamisch steuern.

## Elemente löschen oder hinzufügen

```js
myImage.remove();

let newElement = document.createElement("div");
newElement.textContent = "New Element";
document.body.appendChild(newElement);
```

So kannst du Elemente entfernen, neue erstellen und ins Dokument einfügen.
