# DOM Click Events

Mit Click Events reagiert dein Javascript darauf, dass ein Benutzer auf ein Element klickt.

## Click Event registrieren

```js
myImage.addEventListener("click", function (event) {
  myImage.style.borderColor = "black";
});
```

Sobald auf `myImage` geklickt wird, wird die Funktion ausgeführt.

## Aufbau

```js
element.addEventListener("click", function (event) {
  // Code bei Klick
});
```

- `element` ist das HTML-Element
- `"click"` ist das Event
- `event` enthält Informationen zum Klick

## Für das Click Game

```js
player.addEventListener("click", function () {
  player.style.backgroundColor = "blue";
});
```

So kannst du beim Klick Farbe, Position oder Score verändern.
