# DOM Elemente ansprechen

Bevor du ein HTML-Element verändern kannst, musst du es zuerst im DOM auswählen.

## Ein Element über die `id` auswählen

```js
let myImage = document.getElementById("image");
```

Das sucht ein Element mit `id="image"` und speichert es in der Variable `myImage`.

## Ein Element mit CSS-Selektor auswählen

```js
let myImage = document.querySelector("#image");
let item = document.querySelector(".item");
```

Mit `querySelector()` kannst du CSS-Selektoren verwenden:

- `#image` sucht nach einer `id`
- `.item` sucht nach einer Klasse

## Mehrere Elemente auswählen

```js
let items = document.querySelectorAll(".item");
```

`querySelectorAll()` gibt dir mehrere passende Elemente zurück.

## Für das Click Game

```js
let player = document.getElementById("player");
let scoreDisplay = document.getElementById("score");
let playground = document.getElementById("playground");
```

So bekommst du Zugriff auf die Elemente, die du später verändern willst.
