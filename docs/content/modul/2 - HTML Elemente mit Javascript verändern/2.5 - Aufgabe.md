# Aufgabe - Click Game

Wir bauen Schritt für Schritt ein kleines Spiel, bei dem man auf ein Element klickt, Punkte sammelt und sich das Element bewegt.

### 1: Player auswählen und Farbe ändern

Selektiere mit Javascript das HTML-Element mit der ID `player`. Hilfe dazu findest du in [2.1 - DOM Elemente ansprechen](/modul/2-html-elemente-mit-javascript-veraendern/2-1-dom-elemente-ansprechen).

Ändere danach die Hintergrundfarbe des Players. Hilfe dazu findest du in [2.2 - DOM Elemente verändern](/modul/2-html-elemente-mit-javascript-veraendern/2-2-dom-elemente-veraendern).

### 2: Hintergrundfarbe erst bei Klick ändern

Die Hintergrundfarbe soll sich **erst ändern, wenn man auf den Player klickt**. Verwende dafür ein Click Event aus [2.3 - DOM Click Events](/modul/2-html-elemente-mit-javascript-veraendern/2-3-dom-click-events).

### 3: Position bei jedem Klick verändern

Bei jedem Klick soll sich der Player an eine **zufällige Position** bewegen.

**Tipps:**

- Mit `Math.random()` erhältst du eine Zufallszahl zwischen `0` und `1`.
- Mit `playground.clientWidth` und `playground.clientHeight` kannst du Breite und Höhe des Spielfelds auslesen.
- Verwende die Funktion `setPosition(element, x, y)`. Diese Funktion kommt aus dem BBZ-Game-Framework und setzt das Element an die Position `x` und `y`.

Beispiel:

```js
setPosition(player, 100, 200);
```

### 4: Score hinzufügen

**Ziel:**  
Erstelle einen Score, der bei jedem Klick **um 1 erhöht wird**.

**Tipps:**

- Erstelle eine Variable: `let score = 0;`
- Verwende `textContent`, um den Score im HTML anzuzeigen. Hilfe dazu findest du in [2.2 - DOM Elemente verändern](/modul/2-html-elemente-mit-javascript-veraendern/2-2-dom-elemente-veraendern).

## 5: Bonus

- Ändere die Farbe bei jedem Klick zufällig 🎨
- Mache das Element kleiner, je höher der Score ist
