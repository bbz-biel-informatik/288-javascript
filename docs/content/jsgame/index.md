# Index

Dieser Bereich dokumentiert das kleine BBZ Game Framework.

Das Framework stellt einfache Funktionen bereit, mit denen du HTML Elemente in einem Spiel positionieren, bewegen, Kollisionen prüfen und Tastatureingaben abfragen kannst.
