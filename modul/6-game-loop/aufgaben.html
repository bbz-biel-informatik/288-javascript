6 - Aufgaben: Game Loop ​

🔒 Die Lösungen sind für dieses Kapitel aktuell ausgeblendet.

👉 Übungen herunterladen

Die Theorie zu diesen Aufgaben findest du im Inhalt dieses Kapitels.

Entpacke den Ordner und starte den Live Server auf der index.html im Hauptordner. Alle drei Übungen verwenden das Game Framework. Es ist in der index.html bereits eingebunden.

🎯 6.1 – Bewegung ​

👉 Ordner 1-bewegung

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Bewegung</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <header class="site-header">
      <a href="../index.html">← Übungsauswahl</a>
      <span class="kapitel">Kapitel 6: Game Loop</span>
    </header>

    <main class="app">
      <h1>Bewegung</h1>
      <p class="hint">Der Roboter soll von selbst losfahren.</p>

      <div id="playground">
        <img id="player" src="../assets/robot.png" alt="Roboter" />
      </div>

      <div class="anzeige">
        <p id="statusText">Roboter wartet.</p>
      </div>
    </main>

    <script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>
    <script src="./script.js"></script>
  </body>
</html>

a) Lass den Roboter automatisch von links nach rechts fahren. Gehe so vor:

  • Wähle den Roboter mit document.querySelector(...) aus.
  • Setze ihn mit setPosition(...) an eine Startposition.
  • Erstelle den Game Loop wie im Aufbau eines Game Loops.
  • Bewege ihn im Game Loop mit moveElement(...).

b) Verändere den Code nacheinander so, dass Folgendes geschieht:

  • Der Roboter bewegt sich nach oben.
  • Der Roboter bewegt sich diagonal nach oben rechts.
  • Der Roboter bewegt sich sehr schnell nach rechts.
  • Der Roboter bewegt sich nach unten. Tipp: Verändere die Anfangsposition, um den Effekt zu sehen.
  • Der Roboter bewegt sich sehr langsam nach unten.
  • Der Roboter bewegt sich nach links.

Denke dabei visuell und stelle dir das Spielfeld als Koordinatensystem vor.

c) Erklären: Warum steht setPosition(...) vor dem Game Loop und nicht darin? Teste es und beschreibe, was passiert.

🎯 6.2 – Steuerung ​

👉 Ordner 2-steuerung

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Steuerung</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <header class="site-header">
      <a href="../index.html">← Übungsauswahl</a>
      <span class="kapitel">Kapitel 6: Game Loop</span>
    </header>

    <main class="app">
      <h1>Steuerung</h1>
      <p class="hint">Steuere den Roboter mit den Pfeiltasten und sammle die Energie ein.</p>

      <div id="playground">
        <img id="player" src="../assets/robot.png" alt="Roboter" />
        <div id="energy" class="gameobject energie">⚡</div>
      </div>

      <div class="anzeige">
        <p id="statusText">Roboter wartet.</p>
      </div>
    </main>

    <script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>
    <script src="./script.js"></script>
  </body>
</html>

a) Steuere den Roboter mit den Pfeiltasten. Die Theorie findest du unter Eine Spielfigur mit Tasten steuern. Beachte die genaue Schreibweise der Tastennamen:

RichtungTastenname
rechts"ArrowRight"
links"ArrowLeft"
oben"ArrowUp"
unten"ArrowDown"

b) Setze die Energiekiste (#energy) mit setPosition(...) an eine Stelle im Spielfeld, zum Beispiel 600, 200.

c) Lass die Energiekiste verschwinden, wenn der Roboter sie berührt. Die Theorie dazu steht unter Kollisionen sind ebenfalls Fragen.

💡 Tipp anzeigen

Wähle die Energiekiste einmal vor dem Game Loop aus:

js
let energy = document.querySelector("#energy");

Prüfe danach im Game Loop mit isColliding(...), ob sich player und energy berühren, und lösche sie mit remove().

d) Zeige im statusText an, was gerade passiert, zum Beispiel Energie eingesammelt.

🎯 6.3 – Energie-Spiel ​

👉 Ordner 3-energie

Jetzt bauen wir ein kleines Spiel. Du brauchst dafür alles aus den Kapiteln Variablen, If-Else und Game Loop.

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Energie-Spiel</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <header class="site-header">
      <a href="../index.html">← Übungsauswahl</a>
      <span class="kapitel">Kapitel 6: Game Loop</span>
    </header>

    <main class="app">
      <h1>Energie-Spiel</h1>
      <p class="hint">Fahren braucht Energie. Die Kiste lädt wieder auf.</p>

      <div id="playground">
        <img id="player" src="../assets/robot.png" alt="Roboter" />
        <div id="energy" class="gameobject energie">⚡</div>
      </div>

      <div class="anzeige">
        <p id="energyText">Energie: 100</p>
        <p id="gameStatus">Spiel läuft.</p>
      </div>
    </main>

    <script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>
    <script src="./script.js"></script>
  </body>
</html>

Programmiere Schritt für Schritt:

a) Die Steuerung mit den Pfeiltasten wie in Übung 6.2.

b) Eine Variable energie mit dem Wert 100. Sie steht vor dem Game Loop. Bei jeder Bewegung verliert der Roboter 0.2 Energie.

c) energyText zeigt laufend die aktuelle Energie an, zum Beispiel Energie: 87.

d) Berührt der Roboter die Energiekiste, wird energie wieder auf 100 gesetzt und die Kiste gelöscht.

e) gameStatus zeigt Spiel läuft., solange energie grösser als 0 ist. Sonst erscheint Game Over.

💡 Tipp anzeigen

Die Energie sinkt nur, wenn sich der Roboter tatsächlich bewegt. Die Rechnung gehört deshalb in denselben if-Block wie der Bewegungsbefehl:

js
if (isKeyPressed("ArrowRight")) {
  moveElement(player, speed, 0);
  energie -= 0.2;
}

Für die Anzeige runden wir die Zahl mit Math.round(energie), sonst erscheinen sehr viele Nachkommastellen.

f) Zusatz: Bei Game Over soll sich der Roboter nicht mehr bewegen können. Überlege dir, wo du dafür eine Bedingung einbauen kannst.
