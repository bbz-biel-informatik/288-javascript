6 - Aufgaben: Game Loop ​

🔒 Die Lösungen sind für dieses Kapitel aktuell ausgeblendet.

👉 Übungen herunterladen

Die Theorie zu diesen Aufgaben findest du im Inhalt dieses Kapitels.

Entpacke den Ordner und starte den Live Server auf der index.html. Die Übung verwendet das Game Framework. Es ist in der index.html bereits eingebunden.

Du arbeitest an einem einzigen Projekt. Die drei Aufgaben bauen aufeinander auf: Dein Code aus 6.1 bleibt stehen und wird in 6.2 und 6.3 erweitert. Geschrieben wird alles in der script.js.

Das Spielfeld enthält nur den Roboter und ein Alien. Es gibt keine Knöpfe. Alles, was passiert, steuerst du im Game Loop.

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Übungen 6 - Game Loop</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <header class="site-header">
      <span class="kapitel">Kapitel 6: Game Loop</span>
    </header>

    <main class="app">
      <h1>Der Roboter im Weltall</h1>
      <p class="hint">Alle drei Aufgaben baust du in der <code>script.js</code> aufeinander auf.</p>

      <div id="playground">
        <img id="player" src="./assets/robot.png" alt="Roboter" />
        <img id="alien" class="gameobject" src="./assets/alien.png" alt="Alien" style="left: 600px; bottom: 200px;" />
      </div>
    </main>

    <script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>
    <script src="./script.js"></script>
  </body>
</html>

🎯 6.1 – Den Roboter bewegen ​

a) Lass den Roboter automatisch von links nach rechts fliegen. Gehe so vor:

  • Wähle den Roboter mit document.querySelector(...) aus.
  • Setze ihn mit setPosition(...) an eine Startposition.
  • Erstelle den Game Loop wie im Aufbau eines Game Loops.
  • Bewege ihn im Game Loop mit moveElement(...).

b) Verändere die Zahlen im moveElement(...) nacheinander so, dass Folgendes geschieht:

  • Der Roboter fliegt nach oben.
  • Der Roboter fliegt diagonal nach oben rechts.
  • Der Roboter fliegt sehr schnell nach rechts.
  • Der Roboter fliegt nach unten. Tipp: Verändere die Anfangsposition, um den Effekt zu sehen.
  • Der Roboter fliegt sehr langsam nach unten.
  • Der Roboter fliegt nach links.

Denke dabei visuell und stelle dir das Spielfeld als Koordinatensystem vor.

c) Erklären: Warum steht setPosition(...) vor dem Game Loop und nicht darin? Teste es und beschreibe, was passiert.

🎯 6.2 – Den Roboter mit Tasten steuern ​

Jetzt soll der Roboter nicht mehr von selbst fliegen, sondern auf die Pfeiltasten reagieren. Du arbeitest in derselben script.js weiter.

a) Ersetze das moveElement(...) im Game Loop durch eine if-Anweisung: Der Roboter soll nur nach rechts fliegen, solange die Taste Pfeil rechts gedrückt ist. Die Theorie findest du unter Eine Spielfigur mit Tasten steuern.

b) Ergänze die drei anderen Pfeiltasten. Beachte die genaue Schreibweise der Tastennamen:

RichtungTastenname
rechts"ArrowRight"
links"ArrowLeft"
oben"ArrowUp"
unten"ArrowDown"
💡 Tipp anzeigen

Jede Richtung bekommt eine eigene if-Anweisung. Schreibe sie untereinander in den Game Loop. Mit einem negativen Wert fliegt der Roboter in die Gegenrichtung.

c) Probiere aus, was passiert, wenn du zwei Pfeiltasten gleichzeitig drückst. Erkläre, warum das so ist.

d) Verändere die Geschwindigkeit des Roboters. Verwende dafür eine Variable speed, die vor dem Game Loop steht.

🎯 6.3 – Das Alien einfangen ​

Im Spielfeld steht von Anfang an ein Alien mit der ID alien. Bisher passiert damit nichts. Das ändern wir jetzt - wieder in derselben script.js.

a) Wähle das Alien vor dem Game Loop mit document.querySelector(...) aus und speichere es in einer Variable alien.

b) Lass das Alien verschwinden, sobald der Roboter es berührt. Die Theorie dazu steht unter Kollisionen sind ebenfalls Fragen.

💡 Tipp anzeigen

Prüfe im Game Loop mit isColliding(...), ob sich player und alien berühren, und lösche das Alien mit remove().

c) Statt das Alien zu löschen: Setze es bei einer Berührung mit setPosition(...) an eine neue Stelle. So kannst du es immer wieder einfangen.

d) Zusatz: Zähle mit einer Variable, wie oft der Roboter das Alien schon eingefangen hat, und schreibe die Zahl mit console.log(...) in die Konsole.

💡 Tipp anzeigen

Die Variable steht vor dem Game Loop:

js
let punkte = 0;

Im Game Loop erhöhst du sie bei einer Berührung:

js
punkte = punkte + 1;
