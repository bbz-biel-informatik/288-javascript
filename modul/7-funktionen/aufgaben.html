🎯 7.1 – Begrüssung ​

👉 Ordner 1-begruessung

html
<!doctype html>
<html lang="de">
  <head>

  <body>
    <header class="site-header">
      <a href="../index.html">← Übungsauswahl</a>

    </header>

    <main class="inhalt">
      <div class="card">
        <h1>Begrüssung</h1>
        <p class="hint">Eine Funktion, drei Knöpfe.</p>

        <input id="nameField" type="text" placeholder="Dein Name" />

        <div class="knoepfe">
          <button id="helloButton">Begrüssen</button>
          <button id="byeButton">Verabschieden</button>
          <button id="shoutButton">Laut begrüssen</button>
        </div>

        <p id="messageText" class="resultat">Noch keine Nachricht.</p>
      </div>
    </main>

    <script src="./script.js"></script>
  </body>
</html>

a) Schreibe eine Funktion sayHello(), die in messageText den Text Hallo! anzeigt. Rufe sie beim Klick auf helloButton auf.

Die Theorie findest du unter Funktionen definieren und aufrufen.

💡 Tipp anzeigen

Eine Funktion besteht aus zwei Teilen: der Definition und dem Aufruf.

js
function sayHello() {
  messageText.textContent = "Hallo!";
}

helloButton.addEventListener("click", function () {
  sayHello();
});

b) Erweitere die Funktion mit einem Parameter name. Die Funktion soll Hallo Nora! anzeigen, wenn Nora im Feld nameField steht. Die Theorie dazu steht unter Parameter.

c) Der byeButton soll Tschüss Nora! anzeigen. Schreibe dafür eine zweite Funktion sayBye(name).

d) Der shoutButton ruft deine Funktion sayHello(...) mit einem anderen Wert auf, zum Beispiel sayHello("ALLE ZUSAMMEN").

e) Erklären: Was ist der Unterschied zwischen dem Definieren und dem Aufrufen einer Funktion? Was passiert, wenn du die Funktion nur definierst, aber nie aufrufst?

🎯 7.3 – Game aufräumen ​

👉 Ordner 3-game

In diesem Ordner liegt ein fertiges Energie-Spiel. Es verwendet den Game Loop aus Kapitel 6: Steuerung mit den Pfeiltasten, eine Energiekiste und eine Energie-Anzeige. Der Game Loop ist dabei sehr lang geworden.

script.js

js
// Dieser Code funktioniert bereits. Deine Aufgabe ist es, ihn mit Funktionen aufzuräumen.

let player = document.querySelector("#player");
let energy = document.querySelector("#energy");
let energyText = document.querySelector("#energyText");
let gameStatus = document.querySelector("#gameStatus");

let speed = 3;
let energie = 100;

setPosition(player, 60, 60);
setPosition(energy, 600, 200);

function gameLoop() {
  if (isKeyPressed("ArrowRight")) {
    moveElement(player, speed, 0);
    energie -= 0.2;
  }

  if (isKeyPressed("ArrowLeft")) {
    moveElement(player, -speed, 0);
    energie -= 0.2;
  }

  if (isKeyPressed("ArrowUp")) {
    moveElement(player, 0, speed);
    energie -= 0.2;
  }

  if (isKeyPressed("ArrowDown")) {
    moveElement(player, 0, -speed);
    energie -= 0.2;
  }

  if (isColliding(player, energy)) {
    energie = 100;
    energy.remove();
  }

  energyText.textContent = "Energie: " + Math.round(energie);

  if (energie > 0) {
    gameStatus.textContent = "Spiel läuft.";
  } else {
    gameStatus.textContent = "Game Over";
  }

  window.requestAnimationFrame(gameLoop);
}

gameLoop();

a) Verschiebe die vier if-Blöcke für die Tasten in eine neue Funktion moveRobot() und rufe sie im Game Loop auf. Teste danach, ob sich der Roboter noch genau gleich bewegt.

b) Lagere auch die Anzeige in eine Funktion updateAnzeige() aus. Darin stehen die Zeile mit energyText und die Entscheidung für gameStatus.

c) Dein Game Loop sollte danach nur noch aus wenigen Zeilen bestehen:

js
function gameLoop() {
  moveRobot();
  checkEnergy();
  updateAnzeige();

  window.requestAnimationFrame(gameLoop);
}

Schreibe dafür zusätzlich die Funktion checkEnergy() mit der Kollisionsprüfung.

d) Erklären: Warum ist ein kurzer Game Loop mit Funktionsaufrufen angenehmer zu lesen als ein langer Game Loop?
