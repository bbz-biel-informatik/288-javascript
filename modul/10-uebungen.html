3 - Quizz *** ​

👉 Projekt herunterladen

Wir haben folgendes HTML. Schau dir das HTML an, öffne es im Liveserver und versuche, das Javascript dazu zu komplettieren. Das ziel ist es, dass nach einem Klick auf den Knopf "Prüfen" in der Auswertung 'Richtig!' steht, wenn im Textfeld 'Madrid' eingegeben wurde. Sonst soll 'Falsch' erscheinen.

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Quiz</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <div class="quiz">
      <h1>Quiz</h1>

      <p class="question">Wie lautet die Hauptstadt von Spanien?</p>

      <div class="answer-row">
        <input id="answerInput" type="text" placeholder="Deine Antwort" />
        <button id="checkButton">Prüfen</button>
      </div>

      <p class="result">Auswertung: <span id="result"></span></p>
    </div>

    <script src="./script.js"></script>
  </body>
</html>

script.js

js
let answerInput = document.querySelector("#answerInput");
let checkButton = document.querySelector("#checkButton");
let result = document.querySelector("#result");

// Diese Funktion gibt die Antwort aus dem Textfeld in der Konsole aus.
function checkAnswer(answer) {
  result.textContent = "Hello world";
}

checkButton.addEventListener("click", function () {
  checkAnswer(answerInput.value);
});

Die Funktion checkAnswer() ist schon vorbereitet. Sie liest mit .value den Text, der im Textfeld steht.

5.1 - Dark mode knopf ** ​

👉 Projekt herunterladen

Wir haben folgendes HTML. Schau dir das HTML an, öffne es im Liveserver und versuche, das Javascript dazu zu komplettieren. Das ziel ist es, dass wenn wir auf den Knopf drücken, soll die Website im Darkmode erscheinen. Das heisst: Der Hintergrund scharz und der Text weiss.

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Dark Mode</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body id="page">
    <header class="site-header">
      <b>Meine Website</b>
      <button id="darkModeButton">🌙 Dark Mode</button>
    </header>

    <main class="content">
      <h1>Willkommen!</h1>
      <p>Willkommen auf meiner Website! Hier steht ein kleiner Text.</p>
      <p>Viele Websites haben einen Dark Mode. Er schont am Abend die Augen.</p>
    </main>

    <script src="./script.js"></script>
  </body>
</html>

5.2 - Dark mode knopf *** ​

Erweitere die Aufgabe aus 4.1 so, dass der Knopf wie ein Switch funktioniert: 1x drücken -> Dark mode geht and. Beim nächsten mal drücken -> Dark mode geht off. Hinweis: Du kannst eine Variable verwenden, welche zwischen 0 und 1 wechselt.
