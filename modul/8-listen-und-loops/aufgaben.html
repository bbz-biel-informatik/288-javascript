8 - Aufgaben: Listen und Loops ​

🔒 Die Lösungen sind für dieses Kapitel aktuell ausgeblendet.

👉 Übungen herunterladen

Die Theorie zu diesen Aufgaben findest du im Inhalt dieses Kapitels.

Entpacke den Ordner und starte den Live Server auf der index.html im Hauptordner.

🎯 8.1 – Playlist ​

👉 Ordner 1-playlist

index.html

html
<!doctype html>
<html lang="de">
  <head>
    <meta charset="UTF-8" />
    <title>Playlist</title>
    <link rel="stylesheet" href="./style.css" />
  </head>

  <body>
    <header class="site-header">
      <a href="../index.html">← Übungsauswahl</a>
      <span class="kapitel">Kapitel 8: Listen und Loops</span>
    </header>

    <main class="inhalt">
      <div class="card">
        <h1>Playlist</h1>
        <p class="hint">Eine Liste von Songs steht schon im JavaScript.</p>

        <button id="showButton">Playlist anzeigen</button>

        <p id="listText" class="resultat">Noch nichts angezeigt.</p>
      </div>
    </main>

    <script src="./script.js"></script>
  </body>
</html>

In der script.js ist bereits eine Liste vorbereitet:

js
// Diese Liste ist bereits vorbereitet.
let songs = ["Bohemian Rhapsody", "Lose Yourself", "Rolling in the Deep"];

// Schreibe hier deinen JavaScript-Code.
// Wichtige IDs: showButton, listText

a) Beim Klick auf showButton sollen alle Songs in listText erscheinen. Gehe dafür mit forEach(...) durch die Liste.

💡 Tipp anzeigen

Sammle den Text in einer Variable und hänge bei jedem Durchlauf einen Song an:

js
let text = "";

songs.forEach(function (song) {
  text = text + song + "\n";
});

listText.textContent = text;

\n bedeutet «neue Zeile».

b) Füge der Liste zwei weitere Songs hinzu. Was musst du am Loop ändern?

c) Nummeriere die Songs, sodass 1. Bohemian Rhapsody erscheint. Du brauchst dafür eine Zählvariable aus Kapitel 4.

👉 Ordner 2-karten

Hier verändern wir viele HTML-Elemente auf einmal.

a) Beim Klick auf colorButton sollen alle Karten eine farbige Hintergrundfarbe bekommen. Wähle sie mit document.querySelectorAll(...) aus und gehe mit forEach(...) durch.

💡 Tipp anzeigen

querySelectorAll liefert eine Liste von Elementen. Die Klasse schreiben wir mit einem Punkt:

js
let karten = document.querySelectorAll(".karte");

karten.forEach(function (karte) {
  karte.style.backgroundColor = "gold";
});

b) Der clearButton löscht alle Karten mit remove().

c) Verwende statt "gold" den Framework-Befehl randomColor(), damit jede Karte eine andere Farbe bekommt. Binde dafür das Game Framework in der index.html ein:

html
<script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>

d) Erklären: Was ist der Unterschied zwischen querySelector und querySelectorAll?

🎯 8.3 – Gegner ​

👉 Ordner 3-gegner

Im Spielfeld sind drei Gegner mit der Klasse enemy. Die Steuerung des Roboters ist bereits fertig.

index.html

html
<!doctype html>
<html lang="de">
  <head>

      <div id="playground">
        <img id="player" src="../assets/robot.png" alt="Roboter" />
        <img class="gameobject enemy" src="../assets/enemy.png" alt="Gegner" style="left: 450px; bottom: 70px;" />
        <img class="gameobject enemy" src="../assets/enemy.png" alt="Gegner" style="left: 590px; bottom: 190px;" />

      </div>

    <script src="https://bbz-biel-informatik.github.io/288-javascript/game-framework/bbzgame.js"></script>
    <script src="./script.js"></script>

a) Wähle alle Gegner mit document.querySelectorAll(".enemy") aus und speichere sie in der Variable enemies.

b) Schreibe eine Funktion moveEnemies(), die mit forEach(...) durch alle Gegner geht und jeden mit moveElement(...) um 2 Pixel nach links bewegt.

c) Rufe moveEnemies() im gameLoop() direkt nach moveRobot() auf.

d) Füge in der index.html einen vierten Gegner hinzu. Was musst du am JavaScript ändern?

e) Zusatz: Prüfe mit isColliding(...) im Loop, ob der Roboter einen Gegner berührt, und zeige in statusText Getroffen! an.
