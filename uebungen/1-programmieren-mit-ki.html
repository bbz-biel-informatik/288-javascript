Programmieren mit KI ​

KI wird gerade zum Standard in der Progrmmierung. Nachdem wir nun die Grundlagen angeschaut haben, versuchen wir als letzten Auftrag das Programmieren mit KI zu üben und zu schauen, wie weit wir kommen.

Das Ziel

Das Ziel ist relativ einfach: Wir entscheiden uns für ein Website projekt (Portfolio, Game, Website) und versuchen, das mithilfe von KI möglichst gut umzusetzen.

Der Auftrag

  1. Wählt selber ein Ziel aus. Kann auch etwas sein, woran ihr bereits arbeitet. Schreibe eine Kurze Beschreibung auf unsere gemeinsme Pinwand: https://canva.link/6bzh3ksbodvos58
  2. Versuche, möglichst weit zu kommen
  3. Präsentiert das Ergebnis (kurz)

Methoden

Wir können folgende Methoden anwenden:

Chatbot + VS Code Lasst euch von einem Chatbot (ChatGPT, Gemini, Claude, Le Chat) den Code als eine HTML-Datei mit CSS und JavaScript erstellen. Kopiert ihn in VS Code in eine index.html und öffnet sie mit «Live Server». So seht ihr reines JavaScript, wie im Unterricht gelernt.

Claude Artifacts Auf claude.ai beschreibt ihr euer Projekt, und Claude zeigt es direkt im Chat als Vorschau an («Artifact»). Mit «Publish» erhaltet ihr einen Link zum Teilen. Gratis, aber die Anzahl Nachrichten ist begrenzt. Wichtig: In den Einstellungen unter «Capabilities» muss «Code execution and file creation» aktiviert sein.

Google AI Studio Auf aistudio.google.com beschreibt ihr unter «Build», was ihr wollt, und die KI baut eine ganze Web-App mit Vorschau. Gratis, aber ihr braucht ein Google-Konto. Der Code ist in React geschrieben.

App-Builder Lovable, Bolt.new oder Replit bauen aus einer Beschreibung eine App direkt im Browser. Achtung: Die Gratis-Version ist stark begrenzt, und ihr braucht ein eigenes Konto.

  • https://lovable.dev
  • https://Bolt.new
  • https://replit.com
